# خَطّي (Khatti)

منصة عراقية لتنظيم «خطوط» نقل الطلبة والموظفين والأساتذة في جميع المحافظات — طرفان فقط: **راكب + سائق**.

## الفكرة باختصار
- بحث وحجز مقاعد في الخطوط (بنات فقط / شباب فقط / مختلط)
- تتبع لحظي للباص + رابط ثابت للأهل (يعمل من المتصفح بلا تثبيت)
- منصة إبلاغ عن المخالفات (برصد تلقائي بالـGPS + مراجعة بشرية)
- تقييم متبادل أعمى + تعليقات موثقة + دردشة داخل التطبيق
- «أعلمني عند التوفر» وخريطة طلب توجه السائقين للمسارات المطلوبة
- دفع مسبق عبر Zain Cash / آسيا حوالة — الاشتراك الشهري من السائق هو مصدر الربح الأساسي
