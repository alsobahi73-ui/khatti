# خَطّي (Khatti)

منصة عراقية لتنظيم «خطوط» نقل الطلبة والموظفين والأساتذة في جميع المحافظات — طرفان فقط: **راكب + سائق**.

## جرّب النموذج مباشرة
**https://alsobahi73-ui.github.io/khatti/** — نموذج تفاعلي يعمل من المتصفح (عربي RTL، موبايل أولًا)

## ما فيه
- **الراكب:** بحث (محافظة←منطقة←جهة + فلترة بنات/شباب/مختلط + بحث بالدبوس)، حجز (كاش/Zain Cash/آسيا حوالة)، تتبع لحظي للباص، تقييم أعمى، بلاغ مخالفة، دردشة مع السائق
- **السائق:** لوحة الخط، إدارة المسار والمقاعد وصفة الخط، بث جماعي، تقييم الركاب، الرد على التعليقات
- **الأهل:** رابط ثابت بلا تسجيل دخول — خريطة حية + تنبيهات (صعود/وصول/تأخير/انحراف)
- **الموبايل:** نفس الكود يُبنى كتطبيق أندرويد وآيفون عبر Capacitor — الدليل: `docs/MOBILE-BUILD.md`
