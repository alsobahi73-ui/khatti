# خَطّي (Khatti)

منصة عراقية لتنظيم «خطوط» نقل الطلبة والموظفين والأساتذة في جميع المحافظات — طرفان فقط: **راكب + سائق**.

## جرّب النموذج مباشرة
**https://alsobahi73-ui.github.io/khatti/** — نموذج تفاعلي يعمل من المتصفح (عربي RTL، موبايل أولًا)

## ما فيه
- **الراكب:** بحث (محافظة←منطقة←جهة + فلترة بنات/شباب/مختلط + بحث بالدبوس)، حجز (كاش/Zain Cash/آسيا حوالة)، تتبع لحظي للباص، تقييم أعمى، بلاغ مخالفة، دردشة مع السائق
- **السائق:** لوحة الخط، إدارة المسار والمقاعد وصفة الخط، بث جماعي، تقييم الركاب، الرد على التعليقات
- **الأهل:** رابط ثابت بلا تسجيل دخول — خريطة حية + تنبيهات (صعود/وصول/تأخير/انحراف)
- **الموبايل:** نفس الكود يُبنى كتطبيق أندرويد وآيفون عبر Capacitor — الدليل: `docs/MOBILE-BUILD.md`

## الحالة
`نموذج تفاعلي v0.1` — التحقق الميداني (خط واحد عبر واتساب) قبل أي بناء حقيقي.

## التطوير والاختبارات

المتطلبات: Node.js 22 أو أحدث (التحقق الحالي على 24)، npm، Python 3 لخادم الاختبار، وChromium لاختبارات المتصفح.

```bash
npm ci
npm test
npm run web:pack
python3 -m http.server 4173 --bind 127.0.0.1 --directory www
```

عند عدم وجود Chromium محليًا: `npx playwright install chromium`. يمكن تحديد مساره عبر `CHROMIUM_PATH`. الاختبارات تعمل على `www/` وتتضمن صفحات التسجيل والمسارات، البحث بالدبوس، التحقق من المدخلات، الحجز والبلاغات التجريبية، فشل التخزين وانقطاع الخرائط. سير GitHub Actions مضاف؛ لم يُشغّل على GitHub ضمن التحقق المحلي.

- `assets/data.js`: بيانات العرض الثابتة.
- `assets/demo.js`: تهيئة سجلات المحاكاة المحلية.
- `assets/core.js`: ترتيب المسافة والتحقق من القيم والأهلية؛ مستقل عن DOM وقابل للاختبار.
- `assets/app.js`: أدوات الواجهة والتخزين والمحاكاة. البيانات الجديدة معزولة تحت `khatti_demo_v1_`؛ مفاتيح النموذج القديمة لا تُحذف ولا تُرحّل باعتبارها بيانات حقيقية.

**جميع الوظائف محاكاة:** لا SMS، توثيق هوية، مراجعة بشرية، حجز مقعد فعلي، تحويل أموال، دردشة خارج الجهاز، GPS حقيقي أو إرسال طوارئ. لا تستخدم بيانات شخصية أو وثائق حقيقية. بوابة الحساب المحلية ليست مصادقة أمنية. البيانات قابلة للفقد أو التعديل من المتصفح وليست قاعدة بيانات. لا يعمل رابط الأهل كدعوة آمنة حقيقية.

حزمة الويب ثابتة وتحتاج اتصالًا لتحميل Leaflet من `unpkg.com` وبلاطات `tile.openstreetmap.org`، مع بديل عند الفشل. وجود manifest وحده لا يعني PWA مكتملة: لا يوجد Service Worker أو أيقونات تثبيت، ولا ضمان للعمل دون إنترنت.

تفاصيل الإصلاحات والحدود وخطة المرحلة التالية: [`docs/PHASE1-REPORT.md`](docs/PHASE1-REPORT.md).
