## نتائج التحقق

- `npm ci`: نجح، وأُعيد تشغيله لاختبار التثبيت من القفل.
- `npm test`: **18 حالة ناجحة، 0 فاشلة، 0 متخطاة**: 6 اختبارات Node للمنطق والحزمة والمسارات وصياغة السكربتات، و12 اختبار Chromium لتدفقات الاستخدام.
- اختبارات المتصفح تشمل كل صفحات الحزمة، الروابط بمعرفات غير صالحة، التسجيل والمدخلات، الحجز ومنع التكرار ونفاد المقاعد، عدم الإرسال في الطوارئ، البلاغ غير المطابق، تهريب الاسم، تعديل الخط، اختيار الدبوس عبر Leaflet، أزرار العطل، فساد السجلات وفشل الحفظ، وإيقاف مؤقتات الأهل.
- اختبار الدبوس يستخدم Leaflet 1.9.4 من حزمة npm داخل الاختبار ويمنع طلبات البلاطات؛ اختبارات أخرى تمنع تحميل Leaflet لاختبار البديل. هذا لا يثبت اتصالًا فعليًا بخوادم الخرائط.
- `npm run web:pack`: نجح، وصفحة التسجيل موجودة ضمن 7 مداخل رئيسية منسوخة. خادم Python أعاد HTTP 200 للتسجيل والبحث، وفُحص محتواهما.
- `npx cap add android` و`npx cap add ios` و`npm run mobile:sync`: نجحت تهيئة المنصتين ونسخ الويب؛ تطابقت نسخ التسجيل والمنطق والبحث في كل منصة مع `www/`.
- `npx cap doctor`: تعرف على Capacitor 7.6.9 والمنصة Android، وانتهى بخطأ غياب Xcode. تحذير غياب CocoaPods أثناء مزامنة iOS متوقع على هذه الآلة؛ تثبيت الاعتماديات الأصلية لم يُختبر.
- لا يوجد Android SDK أو `sdkmanager` في البيئة؛ لم يُنفذ بناء APK/AAB. لا يوجد macOS/Xcode/CocoaPods؛ لم يُبن IPA. لا اختبار على أجهزة فعلية أو فحص توقيع/متاجر.
- النطاقان `unpkg.com` و`tile.openstreetmap.org` أعادا رفضًا من وكيل الشبكة الحالي. حُفظت إضافتهما في مسودة إعداد البيئة؛ يلزم تفعيل الإعدادات وإعادة اختبار الاتصال قبل ادعاء عمل الخرائط عبر الإنترنت هنا.
- سير CI مضاف، ولم يُشغّل على GitHub ضمن التحقق المحلي.
