# المحافظات والمدن في البحث

أضيفت المحافظات العراقية الـ19، بما فيها حلبجة، إلى `assets/locations.js` مع 146 اختيارًا لمدن ومناطق رئيسية. هذه قائمة عرض منتقاة، وليست سجلًا إداريًا كاملًا لكل القرى والأحياء أو مرجعًا للحدود الإدارية. يعكس عنوان الحقل ذلك: «المدينة / المنطقة».

اختيار المحافظة يحدّث المدن، ويمسح المدينة والجهة والدبوس السابقين، ويعيد تمركز الخريطة عند وجودها. تحفظ المحافظة والمدينة في فلاتر التبويب، وتستعاد المدينة فقط إذا كانت ضمن المحافظة المستعادة. الاختيار القديم «الموصل» كاسم محافظة يُحوّل إلى نينوى؛ الموصل متاحة الآن كمدينة ضمنها.

الجهات وخطوط العرض ما زالت بيانات بغداد السابقة؛ لا تعرض خطوط بغداد أو جامعاتها وكأنها متاحة في محافظة أخرى. يمكن حفظ طلب توفر تجريبي بالمحافظة والمدينة المختارتين، دون ادعاء إرسال إشعار حقيقي. لم تُضف خدمات أو مسارات تشغيل وهمية.

حدثت حزمة الويب وملف [`demo/khatti-demo.html`](../demo/khatti-demo.html) الموحّد. لا تغييرات في الألوان أو بيانات العملاء أو API التسجيل.

نجحت 9 اختبارات للمنطق والبيانات والحزمة و19 اختبار متصفح. اختبارات الربط تغطي تبديل المحافظات، ومسح المدن القديمة، واستعادة الاختيار وحفظ طلب التوفر، وتوافق الفلاتر القديمة. اختُبرت النسخة الموحّدة أيضًا بما فيها المحافظات الجديدة وتدفق الراكب والسائق والتنقل عبر الشاشات الـ17 دون أخطاء JavaScript.

أصلحت أداة تغليف الملف الموحّد بحيث لا تخلط اسم متغير قائمة المواقع مع كائن تنقل المتصفح، وأضيف اختبار يولّد الحزمة ويشغّل قائمة المدن المضمّنة للتأكد من بقائها سليمة.
