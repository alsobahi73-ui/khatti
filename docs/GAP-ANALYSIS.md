# تحليل الفجوات — خطّي مقابل التطبيقات العالمية
> التاريخ: 2026-10-15. المرجع: PROMPT.md. التطبيقات المقارنة: Swvl (مصر)، Uber Shuttle، Zeelo (بريطانيا/أمريكا)، Via، Uber/Lyft، inDrive/Careem.

## 1. نواقص حرجة (تهم السوق العراقي)

| الفجوة | لماذا تهم | الأولوية |
|---|---|---|
| **تأكيد الصعود لكل رحلة (QR أو PIN)** — كما في Uber Shuttle (مسح QR عند الصعود) وUber (رمز PIN من 4 أرقام يعطيه الراكب للسائق قبل الانطلاق) | يمنع صعود الراكب في باص خاطئ — أخطر سيناريو أمان في خطوط الطلبة، ولا يغطيه توثيق السائق لمرة واحدة | الآن (تصميمًا)، بعد الإطلاق (تنفيذًا) |
| **زر الطوارئ يتصل بأرقام الطوارئ مباشرة مع إرسال الموقع** — كما في Uber/inDrive (زر SOS يشارك الموقع تلقائيًا مع جهة الطوارئ) | زر خطّي الحالي ينبّه الأهل فقط؛ في حادث حقيقي الدقائق تهم ولا يوجد بديل | الآن |
| **اللغة الكردية (سوراني)** | البرومت يعد بـ«كافة محافظات العراق» — إقليم كردستان سوق كامل لا يخدمه تطبيق عربي فقط | بعد الإطلاق |
| **مكالمة صوتية مقنّعة داخل التطبيق** — كما في inDrive (مكالمات VoIP بلا كشف الأرقام) | السائق يقود ولا يستطيع الكتابة؛ تنسيق نقطة الالتقاط صوتيًا ضرورة عملية، والدردشة النصية وحدها لا تكفي | بعد الإطلاق |
| **تحقق دوري من هوية السائق (سيلفي/تحقق حيوية)** — كما في Uber (Real-Time ID Check) وinDrive (تحقق صوري أسبوعي) | يمنع مشاركة الحساب (سائق آخر يقود بحساب موثّق) — ثغرة حقيقية لا يغطيها التوثيق لمرة واحدة عند التسجيل | بعد الإطلاق |

## 2. نواقص متوسطة (بعد الـ MVP)

| الفجوة | لماذا تهم | الأولوية |
|---|---|---|
| **تنبيه استباقي للراكب عند شذوذ الرحلة (RideCheck)** — Uber يرصد التوقف المفاجئ/الانحراف ويسأل الراكب «هل أنت بخير؟» | خطّي يرصد المخالفات تلقائيًا لكنه لا يسأل الراكب لحظيًا؛ السؤال الاستباقي يمنع الحادث قبل وقوعه | لاحقًا |
| **باقات مرنة** — كما في Zeelo/Swvl (أسبوعي، حزمة 10 رحلات، خصم طلاب) | خطّي: يومي/شهري فقط؛ الباقات ترفع الالتزام والإيراد | بعد الإطلاق |
| **مسح الركاب عند الصعود للسائق** — كما في Zeelo (السائق يمسح الراكب عند الصعود) | يلغي «من صعد ومن لم يصعد» اليدوي ويوثّق الحضور للأهل | بعد الإطلاق |
| **برنامج إحالة (ادعُ صديقًا)** — معيار Swvl/Uber | أرخص قناة نمو لخطوط الطلبة (المجموعات الطلابية) | بعد الإطلاق |
| **تسجيل صوتي اختياري أثناء الرحلة** — كما في Uber/inDrive (أسواق مختارة) | رادع للتحرش ودليل موثّق؛ حساسية الخصوصية تجعله اختياريًا ولاحقًا | لاحقًا |
| **حجز لغير حاملي الهواتف الذكية (واتساب/اتصال)** — كما في Via (الحجز عبر الهاتف) | شريحة من الأهالي والسائقين كبار السن خارج التطبيق | لاحقًا |
| **تفضيلات أمان تلقائية** — كما في Uber (مشاركة الرحلة تلقائيًا ليلًا) | طبقة أمان إضافية بلا مجهود من المستخدم | لاحقًا |
| **تقارير أداء موسعة للسائق** (نسبة الالتزام بالمواعيد، تقييم النظافة) | خطّي يعطي الدخل والركاب فقط؛ الأداء التفصيلي يحفّز الجودة | لاحقًا |
| **خيار مركبات لذوي الاحتياجات الخاصة** — كما في Via | فئة مستبعدة حاليًا من كل خطوط العراق | لاحقًا |

## 3. ما يتفوق فيه خطّي أصلًا

- **منصة المخالفات الموثقة بسلم عقوبات** (إنذار ← إيقاف ← حذف + رصد GPS تلقائي + مراجعة بشرية): لا يوجد مثيل لها — Uber/inDrive يعتمدان على التقييم والحظر الصامت فقط.
- **رابط الأهل الثابت بلا تثبيت** (واتساب ← متصفح): عملي أكثر من تطبيق الأهل المنفصل لدى Zeelo، ويناسب العادات التقنية للأهالي في العراق.
- **صفة الخط (بنات/شباب/مختلط) كمخالفة جسيمة عند الإعلان الكاذب**: تكييف ثقافي لا مثيل غربي له.
- **خريطة الطلب المعروضة للسائقين**: Via تتنبأ بالطلب داخليًا؛ عرضه كأداة استقطاب للسائقين فكرة مميزة.
- **التقييم المتبادل الأعمى** (منع الانتقام): لا تطبقه تطبيقات النقل العالمية.
- **رحلات العطل والمناسبات** (إعلان/طلب مقاعد لمرة واحدة): لا يوجد مقابل مباشر — inDrive بين-المدن أقرب شيء وهو نموذج مختلف.
- **الدفع النقدي + المحافظ المحلية** (Zain Cash/آسيا حوالة): التطبيقات العالمية مبنية على البطاقات — غير صالحة للعراق.

## 4. ما استُبعد عمدًا (غير صالح للعراق)

- الدفع بالبطاقات / المحافظ الرقمية الغربية (لا PayPal/Stripe في العراق).
- فحص السوابق عبر قواعد بيانات حكومية رقمية (غير متوفرة) — يُستعاض عنه بالمراجعة البشرية + صورة الإجازة.
- مؤشرات «مناطق الخطر» (inDrive) — غير ملائمة لسياق خطوط ثابتة معروفة.
