# نسخة التجربة في ملف واحد

الملف: [`demo/khatti-demo.html`](../demo/khatti-demo.html).

نزّل الملف وافتحه في متصفح يدعم ملفات HTML. لا يحتاج تثبيت Node أو تشغيل API. اختر راكبًا أو سائقًا، وأدخل بيانات وهمية، واستخدم أي رمز من **4 أرقام**. جرّب التسجيل ثم البحث وبطاقة الخط ومراجعة الحجز والتأكيد.

تشمل النسخة تحسينات رحلة التسجيل والبحث وأول حجز. جميع الحسابات والشارات والتوثيق والحجز والدفع والتتبع والطوارئ **محاكاة**، دون إرسال للسائق أو مزود SMS أو جهة طوارئ. هذه ليست تجربة الحفظ في قاعدة الخادم؛ بيانات التجربة معزولة في متصفحك، وقد تصبح مؤقتة إن منع المتصفح التخزين. زر «بدء تجربة جديدة» يمسح بيانات هذه النسخة فقط.

ملفات الواجهات وLeaflet وصوره مضمنة داخل HTML؛ بلاطات الخريطة تحتاج الإنترنت. بعض تطبيقات عرض الملفات لا تشغل JavaScript؛ افتح الملف في متصفح، لا كمعاينة مستند داخل تطبيق مراسلة. لا توجد APK أو IPA في هذا التسليم.

لإعادة توليد النسخة من جذر المستودع بعد `npm ci`:

```bash
node scripts/pack-demo.js demo/khatti-demo.html
```

أداة التغليف تقرأ صفحات الواجهة والأصول فقط، ولا تضم خادم API أو قاعدة البيانات أو المفاتيح أو بيانات المستخدمين. تستخدم تنقلًا داخليًا بين الشاشات للحفاظ على الملف واحدًا، ولا تعدل ملفات التطبيق الأصلية. ترخيص Leaflet مرفق داخل الملف.

اختُبر الملف عبر Chromium على خادم محلي لاختبار المحتوى نفسه: تسجيل الراكب والسائق، التنقل والبحث والحجز واستمرار بيانات المتصفح. فتح `file://` مباشرة داخل متصفح بيئة التنفيذ محجوب بسياسة تلك البيئة؛ لذلك لا يُدّعى اختباره مباشرة على جهازك أو على Safari/Android/iOS.
